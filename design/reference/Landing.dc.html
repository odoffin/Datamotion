How a lesson works

you type

Every query is yours.

There is no copy and paste. Each lesson hands you a request slip with a mistake on it. Fix it, run it, and the database answers with real rows. Any query that returns the right rows passes, so there is more than one correct answer.

Your query

SELECT * FROM orders WHERE 50 < amount

Approved. Your query returned the same 17 rows as the goal.

it points

A wrong word gets circled.

Datapen finds the exact word that is wrong, circles it in red pen and tells you what it expected. You see the one word to fix, not a wall of error text.

Your query

SELECT * FORM orders WHERE amount > 50

expected FROM

Word 2 should be “FROM”, but you typed “FORM”.

see it run

Watch your own query run.

The animation is built from the query you typed. Rows are kept or dropped the way the database decides, and the rows left at the end match the real result. Pause it, step back, or play it again.

Step 3 of 19

Rows 1 and 4 pass; rows 2, 3 and 5 fail.
